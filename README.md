## จุดมุ่งหมายและวัตถุประสงค์

### จุดมุ่งหมายของรายวิชา

1. ศึกษาหลักการการออกแบบและพัฒนานวัตกรรม
2. ฝึกปฏิบัติวิเคราะห์และออกแบบเนื้อหา
3. สามารถจัดการเรียนรู้ สร้าง ทดสอบ และประเมินคุณภาพนวัตกรรม
4. สามารถสร้างนวัตกรรมทางด้านคอมพิวเตอร์ศึกษา

### วัตถุประสงค์ในการพัฒนาและปรับปรุงรายวิชา

1. ให้นักศึกษามีความรู้ที่เป็นรูปธรรมในการพัฒนานวัตกรรมทางการศึกษา
2. ให้นักศึกษาสามารถพัฒนานวัตกรรมทางการศึกษาได้อย่างเหมาะสม

รหัสผลการเรียนรู้ตามตารางประเมินในต้นฉบับ:

- การสอบกลางภาค สอบปฏิบัติ และสอบปลายภาค: `2(1), 2(2)`
- การเข้าชั้นเรียนและการมีส่วนร่วม: `1(2), 1(4), 4(3), 4(4)`
- กรณีศึกษา ค้นคว้า การนำเสนอ งานกลุ่มและผลงาน: `1(2), 1(4), 3(2), 3(3), 4(3), 4(4), 5(1), 5(2), 5(3), 6(2), 6(4)`

**หมายเหตุ:** ปรับแผนการสอนเป็น 16 สัปดาห์ โดยกำหนดสอบปลายภาคในสัปดาห์ที่ 16 สัดส่วนคะแนนคงตาม มคอ.3 ส่วนเกณฑ์ช่วงคะแนนสำหรับตัดเกรดไม่ได้ระบุไว้ในเอกสารต้นฉบับ

## ทรัพยากรประกอบการเรียน

- **เอกสารและตำราหลัก:** เอกสารประกอบการสอน การพัฒนานวัตกรรมด้านคอมพิวเตอร์ศึกษา
- **เอกสารและข้อมูลสำคัญ:** ไม่ระบุ
- **เอกสารและข้อมูลแนะนำ:** เว็บไซต์ที่เกี่ยวข้องกับหัวข้อในประมวลรายวิชา รวมถึงยูทูป เฟซบุ๊ค และติ๊กตอก

## การประเมินรายวิชาและกระบวนการปรับปรุง

### การประเมินประสิทธิผลของรายวิชาโดยนักศึกษา

- สนทนากลุ่มระหว่างผู้สอนและผู้เรียน
- สะท้อนคิดจากพฤติกรรมของผู้เรียน
- ใช้แบบประเมินผู้สอนและแบบประเมินรายวิชา

### การประเมินการสอน

- พิจารณาผลการสอบ
- ทวนสอบผลประเมินการเรียนรู้

### การปรับปรุงการสอน

- สัมมนาการจัดการเรียนการสอน
- วิจัยในและนอกชั้นเรียน

### การทวนสอบมาตรฐานผลสัมฤทธิ์

สุ่มตรวจการให้คะแนนผลงานนักศึกษาโดยอาจารย์อื่นหรือผู้ทรงคุณวุฒิที่มีความรู้ในวิชานี้ และตั้งคณะกรรมการในสาขาวิชาตรวจสอบข้อสอบ รายงาน วิธีให้คะแนนสอบ และคะแนนพฤติกรรม

### การทบทวนและวางแผนปรับปรุงรายวิชา

ปรับปรุงรายวิชาทุก 3 ปี หรือตามข้อเสนอแนะและผลการทวนสอบมาตรฐานผลสัมฤทธิ์ รวมถึงเปลี่ยนหรือสลับอาจารย์ผู้สอนทุกปี เพื่อให้นักศึกษาได้มุมมองการประยุกต์ความรู้กับปัญหาจากงานวิจัยหรืออุตสาหกรรมที่หลากหลาย
