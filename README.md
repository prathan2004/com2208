## หมวดที่ 2 จุดมุ่งหมายและวัตถุประสงค์

### จุดมุ่งหมายของรายวิชา

1. ศึกษาหลักการการออกแบบและพัฒนานวัตกรรม
2. ฝึกปฏิบัติวิเคราะห์และออกแบบเนื้อหา
3. สามารถจัดการเรียนรู้ สร้าง ทดสอบ และประเมินคุณภาพนวัตกรรม
4. สามารถสร้างนวัตกรรมทางด้านคอมพิวเตอร์ศึกษา

### วัตถุประสงค์ในการพัฒนาและปรับปรุงรายวิชา

1. ให้นักศึกษามีความรู้ที่เป็นรูปธรรมในการพัฒนานวัตกรรมทางการศึกษา
2. ให้นักศึกษาสามารถพัฒนานวัตกรรมทางการศึกษาได้อย่างเหมาะสม

## หมวดที่ 3 ลักษณะการดำเนินการ

### คำอธิบายรายวิชา

หลักการการออกแบบและพัฒนานวัตกรรม การวิเคราะห์และออกแบบเนื้อหา ระบบการจัดการเรียนรู้ สร้าง ทดสอบ ประเมินคุณภาพนวัตกรรม การประยุกต์ใช้กระบวนการคิดเชิงออกแบบในการสร้างนวัตกรรมทางด้านคอมพิวเตอร์ศึกษา

### เวลาเรียนและการให้คำปรึกษา

| รูปแบบ | จำนวนชั่วโมง |
| --- | --- |
| บรรยาย | 30 ชั่วโมงต่อภาคการศึกษา |
| ฝึกปฏิบัติ | 30 ชั่วโมงต่อภาคการศึกษา |
| ศึกษาด้วยตนเอง | 5 ชั่วโมงต่อสัปดาห์ |
| สอนเสริม | ตามความต้องการของนักศึกษา เป็นกลุ่มหรือเฉพาะราย |
| ให้คำปรึกษา | 1 ชั่วโมงต่อสัปดาห์ สำหรับนักศึกษาที่ต้องการ เป็นรายบุคคลหรือรายกลุ่ม |

ผู้สอนประกาศเวลาให้คำปรึกษาผ่านเว็บไซต์คณะ

## หมวดที่ 4 การพัฒนาการเรียนรู้ของนักศึกษา

มคอ.3 กำหนดการพัฒนาผู้เรียนไว้ 6 ด้าน โดยสรุปสาระสำคัญดังนี้

| ด้าน | สาระสำคัญ |
| --- | --- |
| คุณธรรม จริยธรรม | ยึดมั่นในวิชาชีพครู มีความรับผิดชอบ ซื่อสัตย์ เคารพสิทธิผู้อื่น และไม่ลอกเลียนผลงาน |
| ความรู้ | เข้าใจหลักการและเนื้อหาวิชาชีพครูและวิชาเอก บูรณาการความรู้กับการปฏิบัติ และประยุกต์เทคโนโลยีเพื่อพัฒนาผู้เรียน |
| ทักษะทางปัญญา | วิเคราะห์และประเมินข้อมูล คิดสร้างสรรค์ แก้ปัญหา และสร้างหรือประยุกต์ใช้นวัตกรรม |
| ความสัมพันธ์ระหว่างบุคคลและความรับผิดชอบ | ทำงานร่วมกับผู้อื่น รับผิดชอบต่อตนเองและส่วนรวม |
| การวิเคราะห์เชิงตัวเลข การสื่อสาร และการใช้เทคโนโลยีสารสนเทศ | ใช้ข้อมูล การสื่อสาร และเทคโนโลยีสารสนเทศในการเรียนรู้และนำเสนอผลงาน |
| วิธีวิทยาการจัดการเรียนรู้ | วิเคราะห์ผู้เรียน ออกแบบกิจกรรมและสื่อ จัดการเรียนรู้ผ่านการปฏิบัติ และพัฒนาทักษะของผู้เรียน |

### แนวทางการสอนและประเมิน

ใช้การบรรยาย อภิปราย ค้นคว้า งานรายบุคคลและงานกลุ่ม การนำเสนอ และการฝึกปฏิบัติ ประเมินจากการส่งงาน ความซื่อสัตย์และการอ้างอิง ผลงานรายบุคคลและกลุ่ม การนำเสนอ การสอบข้อเขียนและปฏิบัติ ตลอดจนการสังเกตการปฏิบัติงาน ตามด้านการเรียนรู้ที่ระบุใน มคอ.3

| กิจกรรมการประเมิน | สัปดาห์ที่ประเมิน | สัดส่วน |
| --- | --- | ---: |
| สอบกลางภาค | 8 | 25% |
| สอบปฏิบัติ | 16 | 10% |
| สอบปลายภาค | 17 | 25% |
| การเข้าชั้นเรียน | ตลอดภาคการศึกษา | 10% |
| การมีส่วนร่วม อภิปราย และเสนอความคิดเห็นในชั้นเรียน | ตลอดภาคการศึกษา | 10% |
| วิเคราะห์กรณีศึกษา ค้นคว้า การนำเสนองาน การทำงานกลุ่มและผลงาน | ตลอดภาคการศึกษา | 20% |

รหัสผลการเรียนรู้ตามตารางประเมินในต้นฉบับ:

- การสอบกลางภาค สอบปฏิบัติ และสอบปลายภาค: `2(1), 2(2)`
- การเข้าชั้นเรียนและการมีส่วนร่วม: `1(2), 1(4), 4(3), 4(4)`
- กรณีศึกษา ค้นคว้า การนำเสนอ งานกลุ่มและผลงาน: `1(2), 1(4), 3(2), 3(3), 4(3), 4(4), 5(1), 5(2), 5(3), 6(2), 6(4)`

**หมายเหตุ:** ตารางแผนการสอนไม่ระบุสัปดาห์สอบปลายภาค แต่ตารางการประเมินระบุสัปดาห์ที่ 17 ส่วนเกณฑ์ช่วงคะแนนสำหรับตัดเกรดไม่ได้ระบุไว้ในเอกสารต้นฉบับ

## หมวดที่ 6 ทรัพยากรประกอบการเรียน

- **เอกสารและตำราหลัก:** เอกสารประกอบการสอน การพัฒนานวัตกรรมด้านคอมพิวเตอร์ศึกษา
- **เอกสารและข้อมูลสำคัญ:** ไม่ระบุ
- **เอกสารและข้อมูลแนะนำ:** เว็บไซต์ที่เกี่ยวข้องกับหัวข้อในประมวลรายวิชา รวมถึงยูทูป เฟซบุ๊ค และติ๊กตอก

## หมวดที่ 7 การประเมินรายวิชาและกระบวนการปรับปรุง

### การประเมินประสิทธิผลของรายวิชาโดยนักศึกษา

- สนทนากลุ่มระหว่างผู้สอนและผู้เรียน
- สะท้อนคิดจากพฤติกรรมของผู้เรียน
- ใช้แบบประเมินผู้สอนและแบบประเมินรายวิชา

### การประเมินการสอน

- พิจารณาผลการสอบ
- ทวนสอบผลประเมินการเรียนรู้

### การปรับปรุงการสอน

- สัมมนาการจัดการเรียนการสอน
- วิจัยในและนอกชั้นเรียน

### การทวนสอบมาตรฐานผลสัมฤทธิ์

สุ่มตรวจการให้คะแนนผลงานนักศึกษาโดยอาจารย์อื่นหรือผู้ทรงคุณวุฒิที่มีความรู้ในวิชานี้ และตั้งคณะกรรมการในสาขาวิชาตรวจสอบข้อสอบ รายงาน วิธีให้คะแนนสอบ และคะแนนพฤติกรรม

### การทบทวนและวางแผนปรับปรุงรายวิชา

ปรับปรุงรายวิชาทุก 3 ปี หรือตามข้อเสนอแนะและผลการทวนสอบมาตรฐานผลสัมฤทธิ์ รวมถึงเปลี่ยนหรือสลับอาจารย์ผู้สอนทุกปี เพื่อให้นักศึกษาได้มุมมองการประยุกต์ความรู้กับปัญหาจากงานวิจัยหรืออุตสาหกรรมที่หลากหลาย
